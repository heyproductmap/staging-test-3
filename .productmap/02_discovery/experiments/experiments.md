# Validation Experiments — Overview

> Phase 2 — Discovery

Discovery-phase experiments test your riskiest assumptions before you build. Every "Assumed" block on the [Lean Canvas](../../01_strategy/business-model/business-model.md) and every belief behind a roadmap item should map to a hypothesis here. Run the cheapest test that could kill the idea, and log every result — validated or not.

> Order by risk: test the assumption that, if wrong, kills the startup fastest.

## Experiment Types

| Type | What it is | Best for testing |
|------|-----------|------------------|
| **Landing page / smoke test** | A page describing the offer with a real CTA; measure conversion | Demand and messaging |
| **Concierge** | Deliver the value manually to a handful of customers | Whether the outcome is actually valuable |
| **Wizard-of-Oz** | Real-looking product with humans behind the curtain | Solution fit before engineering |
| **Presale / LOI** | Ask for money or a signed commitment before building | Willingness to pay |
