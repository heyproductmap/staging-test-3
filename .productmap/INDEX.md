# .productmap — Startup Knowledge Index

This is your startup knowledge base: a lean, founder-focused library covering company context, strategy, discovery, analysis, delivery, and operations. Fill in project-specific content as you validate and build.

> **For agents:** Read this index before searching the tree. Company facts, product, and fundraising → `00_company/`. Business model, PMF, segments, and roadmap → `01_strategy/`. Research, experiments, GTM, and sales → `02_discovery/`. Metrics and economics → `03_analysis/`. Backlog and specs → `04_delivery/`. Finance and legal → `05_operations/`. Raw exports → `06_data/`.

## 00 — Company

Company facts, product definition, and fundraising.

- [team.md](00_company/team.md) — **Founding team roster.** Content: founders table (role, focus, contact), advisors and angels, ways of working. Use when: ownership questions, team context, intros.
- [resources.md](00_company/resources.md) — **Link inventory.** Content: tables for product docs, code repos, analytics, pitch materials, banking/legal vault, comms channels. Use when: locating systems, dashboards, or shared accounts.
- [product/onepager.md](00_company/product/onepager.md) — **Product one-pager.** Content: one-liner, what it does, components, target users, value prop, scope boundaries + agent CTA. Use when: quick product summary, positioning, onboarding context.
- [product/value-proposition.md](00_company/product/value-proposition.md) — **Value proposition.** Content: jobs, pains, gains, pain relievers, gain creators, fit assessment + agent CTA. Use when: positioning, messaging, checking product–customer fit.
- [product/product-vision.md](00_company/product/product-vision.md) — **Product vision template.** Content: vision statement, world view, pillars, differentiators, evidence, boundaries + agent CTA. Use when: long-term direction, strategic pillars.
- [fundraising/fundraising-strategy.md](00_company/fundraising/fundraising-strategy.md) — **Fundraising strategy.** Content: round plan, target raise, use of funds, milestones the raise unlocks, timeline + agent CTA. Use when: planning or running a raise.
- [fundraising/pitch-deck.md](00_company/fundraising/pitch-deck.md) — **Pitch deck outline.** Content: 10–12 slide structure with per-slide guidance and placeholders. Use when: building or reviewing the investor deck.
- [fundraising/investor-pipeline.md](00_company/fundraising/investor-pipeline.md) — **Investor pipeline tracker.** Content: firm/partner table, intro paths, stage fit, status, next steps, follow-up cadence. Use when: managing investor conversations.
